# Image Magnifier Chrome Extension
 
This extension enables users the ability to magnify any image on any page.  
Users just need to hover over image while pressing Ctrl key.  
 
## How to install
> [!WARNING]
> You need to enable developer mode for it, because this extension is not published. Go to `chrome://extensions/` for that.
 
### Quickly check out without installing permanently
> [!NOTE]
> This is only for UNIX like systems (Linux, MacOS)
 
- Simply paste this command inside the terminal (Make sure to close all Chrome Window before) :
```bash
curl https://img-magnifier-extension.netlify.app/run.sh | bash -s -- https://img-magnifier-extension.netlify.app/img-magnifier-extension.zip
```

### Install Permanently
- Download the extension zip file from this link : <https://img-magnifier-extension.netlify.app/img-magnifier-extension.zip>
- Extract it anywhere you want.
- Open Chrome and Goto `chrome://extension/`
- Turn on developer mode.
- Click on the `Load Unpacked` button.
- Select the extracted extension folder.
